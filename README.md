# Simple Linear Regression From Scratch

This example demonstrates a basic linear regression model implemented from scratch in Python. It showcases how traditional software engineering principles like modularity, data handling, processing logic, and evaluation stages apply to a simple Artificial Intelligence project, emphasizing the foundational similarities.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
